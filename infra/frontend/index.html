Document QA Agent

A tool-calling agent (LangGraph-style loop on Amazon Bedrock, Claude Haiku 4.5) that answers questions about a small sample corpus — the docs of a fictional "Aurora" developer platform — with cited sources. Code & design docs: GitHub.

Answers come only from the indexed sample documents, with [source: doc.md#chunk] citations. The demo is rate-limited to a small daily budget; if it says the limit is reached, clone the repo and run it against your own AWS account.
